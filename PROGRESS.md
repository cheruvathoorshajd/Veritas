# Veritas — Progress Audit

Audit date: 2026-04-25. Baseline tsc + lint + build pass clean.

## (1) Fully working

- **Agents (lib/agents/)** — claim-extraction, verification (ReAct ≤3 iters), verdict, report. All wrapped with `langsmith/traceable` (`project_name: 'veritas'`).
- **LangGraph state machine** — `lib/agents/graph.ts` with conditional edges START → extract_claims → verify_claim ↔ synthesise_verdict ↔ next_claim → generate_report → END.
- **API routes** — `/api/pipeline` (SSE), `/api/session`, `/api/session/[id]`, `/api/session/[id]/report`, `/api/transcribe`, `/api/diarize`, `/api/health`.
- **SSE streaming** — `lib/utils/stream.ts` custom ReadableStream; pipeline emits `stage`, `transcript_line`, `claim_detected`, `verifying`, `verdict`, `approval_required`, `speaker_update`, `complete`, `error` events.
- **Rate limiting** — in-memory, 10 req/min per IP on `/api/pipeline`.
- **Retrieval** — Tavily, Wikipedia REST + search fallback, PolitiFact RSS (15-min cache). All sources catch-and-return-empty on failure.
- **NLP fallbacks** — NLI classifier and document compression both fall back to heuristics when Gemini is unavailable.
- **Session storage** — Supabase when configured; in-memory `Map` fallback for dev/demo.
- **Demo mode** — `runDemo()` in `AppShell.tsx` makes zero external calls; uses `demoData.ts`.
- **Frontend** — landing (Hero, Problem, Novelties, Pipeline, Market, ProductCTA) + app (AppShell, Header, InputSection, Mic/File/Text, PipelineBar, TranscriptFeed, VerdictFeed, SpeakerScores, ExportButton).
- **Editorial Brutalist design system** — CSS variables in `globals.css`, hairline borders, parenthetical section labels.
- **HTML report export** — `/api/session/[id]/report` returns printable HTML for browser print-to-PDF.
- **Type/lint/build** — `pnpm tsc --noEmit`, `pnpm lint`, `pnpm build` all clean.
